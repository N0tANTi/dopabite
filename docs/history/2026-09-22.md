# 2026-09-22 public repository and backend decision

- Created the public GitHub repository `https://github.com/N0tANTi/dopabite` and linked the production homepage.
- Replaced the README with a concise Chinese overview, live URL, feature list, setup instructions, data boundaries, and acknowledgements for `poi-marker` and Tastemap.
- Published a clean root history to keep the deleted local QA document and its machine-specific paths out of the public repository. The original local commits are retained in `archive/pre-public-history-20260922` and are intentionally not pushed.
- Verified that `.env.local`, credentials, dependencies, build output, and unused local assets are excluded from the public snapshot.
- Chose a progressive identity design: anonymous session for the first rating, Passkey for low-friction binding, future WeChat QR login, and email OTP only as a fallback.
- Chose a same-origin Node.js API with Better Auth and SQLite WAL for the first shared-rating backend. The decision reflects the current 2-core, 2 GB Tencent host and keeps persistent data outside release directories.
- Recorded the data model, API boundary, anti-abuse rules, privacy controls, backup requirements, local-rating import, and PostgreSQL migration triggers in `docs/architecture/shared-ratings.md`.
